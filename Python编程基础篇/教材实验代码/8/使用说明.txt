第8章　代码使用说明

一、安装依赖
在PythonProject文件夹打开终端，执行：
python -m pip install -r requirements.txt
安装命令应在终端执行，不要写入Python代码文件。

二、运行SQLite示例
按章节目录找到需要学习的.py文件，在编辑器中运行，或在终端执行：
python "示例文件的路径.py"
SQLite无需另装数据库服务。基础操作和学生管理示例大多使用内存数据库，程序退出后数据不保留。
学生管理系统示例需保留同目录的school.py和专业表.csv；各示例可独立运行。

三、运行MySQL示例
1. 安装并启动MySQL，在MySQL客户端创建练习数据库：
CREATE DATABASE book_ch08_demo CHARACTER SET utf8mb4;

2. 在运行代码的同一个PowerShell终端设置连接参数：
$env:BOOK_MYSQL_HOST='127.0.0.1'
$env:BOOK_MYSQL_PORT='3306'
$env:BOOK_MYSQL_USER='root'
$env:BOOK_MYSQL_PASSWORD='你的MySQL密码'
$env:BOOK_MYSQL_DATABASE='book_ch08_demo'
请将用户名、密码及端口替换为自己的实际配置。如果使用编辑器的运行按钮，也需为该运行环境配置这些变量。
需要使用CA证书时，可另设置BOOK_MYSQL_SSL_CA为证书文件的完整路径。

3. 保留原有文件夹结构和mysql_common.py，再运行相应示例。
多数MySQL示例会重建练习库中的演示表并填入数据，请只使用专用练习数据库，不要存放需要保留的数据。示例限制数据库名以book_ch08_开头；权限示例固定使用book_ch08_demo。

4. “4.数据控制语言.py”和“3.创建用户管理员示例.py”需要有创建用户、授权等权限的数据库账号。它们会创建临时演示账户，并在正常执行完成后删除。
.sql文件应在MySQL客户端执行，不要当作.py运行。

四、学习提示
示例已修正教材中的部分错误，具体位置见问题.txt。
示例使用演示数据，查询人数、分页结果和数据库版本等输出可能与教材不同；分页为空或更新影响0行时，请先检查数据是否满足查询条件。
school.py和mysql_common.py为公共支持模块，不要随意移动或删除。
