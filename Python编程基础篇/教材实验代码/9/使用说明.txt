第9章　代码使用说明

一、准备环境
使用带tkinter的Python环境。在PythonProject文件夹打开终端，执行：
python -m pip install -r requirements.txt
此命令安装wxPython；tkinter通常随Python发行版提供。
如导入tkinter失败，请检查所用Python环境是否安装了Tcl/Tk组件。

二、运行基础示例
按章节目录找到对应的.py文件，在编辑器中运行，或在终端执行：
python "示例文件的路径.py"
组件、布局和事件示例会打开独立窗口。按照界面提示点击按钮、输入内容或选择选项；关闭窗口后程序退出。

三、运行学生信息管理系统
入口文件：
9.4完整的例子学生管理系统/9.4.2用户界面构建代码/1.学生信息管理系统.py

1. 保留入口文件同目录下的student_store.py和学生表.txt。
2. 启动程序，首次使用时点击“创建学生数据库”，确认后导入两条演示记录。
3. 添加学生时，专业编号填写M1、M2或M3；性别填写男或女；生日使用YYYY-MM-DD格式；奖学金填写非负数，党员填写0或1，也可留空。
4. 查询时输入需要显示的记录数，必须为正整数。
5. 删除时填写要删除的学生学号。

四、数据文件说明
student.db默认保存在综合系统脚本所在文件夹。再次点击“创建学生数据库”会重置其中的演示表，请在确认前留意是否需要保留已有记录。
学生表.txt是配套演示数据，采用GBK编码、无表头，每行9列。自行编辑时请保持编码及列结构一致。
如需更换数据库位置，可设置环境变量BOOK_STUDENT_DB为目标数据库文件路径。
本章系统使用独立数据库，无需先运行第8章代码。
