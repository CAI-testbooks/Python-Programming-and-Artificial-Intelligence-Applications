# 📘 Python编程与人工智能应用：Python编程基础篇

> **课程简介**：本书是《Python编程与人工智能应用》的上册，聚焦编程能力体系构建，设置三部分。第一部分“Python基础知识”系统讲解从环境配置、语法精要到面向对象设计的完整知识链，通过异常处理、文件操作等工程实践培养规范化编程思维；第二部分“高级工程进阶”聚焦Python语言在工程应用中的拓展能力，系统讲解从数据库连接与操作、图形用户界面构建到网络爬虫开发的核心技术路径；第三部分“智能数据分析与处理”深度融合NumPy矢量化运算、Pandas数据管道构建及Matplotlib可视化技术，建立数据科学方法论。
