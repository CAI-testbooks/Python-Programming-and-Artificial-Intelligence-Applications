# 📘 Python编程与人工智能应用：Python编程基础篇
> **课程简介**：本仓库为《Python编程与人工智能应用：Python编程基础篇》教材配套资源库，聚焦编程能力体系构建，设置“Python基础知识—高级工程进阶—智能数据分析与处理”三部分，系统讲解从环境配置、语法精要、面向对象设计到数据库、GUI、网络爬虫及NumPy/Pandas/Matplotlib数据分析与可视化的完整知识链，并融入国产深度学习框架（Jittor、MindSpore）等自主技术，可作为高等院校人工智能、计算机科学与技术及相关理工科专业本科生的课程教材。
