# 📘 Python编程与人工智能应用

> **课程简介**：人工智能正在逐步改变人们的工作、学习和生活方式。从智能家居设备到自动驾驶汽车，从个性化医疗到智能教育平台，人工智能的影响已渗透到社会的各个领域。因此，为每一位大学生提供人工智能的通识教育变得尤为重要。人工智能通识教育不仅有助于学生建立对人工智能技术的基本认知，理解其对社会和个人生活的潜在影响，还能培养他们在未来职业生涯中所需的关键技能。未来社会亟须具备跨学科思维和创新能力的复合型人才，能够将人工智能融入各行各业，推动产业的智能化升级。

> 学习人工智能的前提是掌握编程技能。编程是我们与计算机沟通的桥梁，是实现算法和模型的基础工具。缺乏扎实的编程能力，人工智能的理论将难以付诸实践，更无法创造有价值的应用。在众多编程语言中，Python 以其简洁易学、功能强大和丰富的生态系统，成为人工智能领域的首选语言。Python 的灵活性和高效性，使其在数据分析、机器学习和深度学习等方面表现出色。

> 本书正是在这一趋势下应运而生的。以人工智能与 Python 的深度融合为核心，结合国家对人工智能复合型人才培养的战略需求，系统讲解了 Python 在人工智能领域的基本原理和实际应用。通过理论阐释与案例实践相结合的方式，帮助读者全面理解人工智能技术的关键内容及其在不同领域的实际价值。本书精选了多个典型场景的应用实例，还特别融入了国产自主技术，如国产深度学习框架计图（Jittor）和昇思（MindSpore），旨在引导读者掌握人工智能的核心技术，更好地应对技术革新带来的挑战与机遇，培养具备实践能力和创新意识的专业人才，为推动国产 AI 技术创新的学者和开发者提供助力。
